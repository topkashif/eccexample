Lesson 11 · first-branch debugging

Separate “SecOC was called” from “SecOC initialized successfully”

You reached SecOC_RxIndication() from CANoe. Now determine which gate stops it: module state, generated SecOC RX PDU ID, or the next parameter/length checks.

First question: does !SecOC_IsInitialized() evaluate true, or does execution fall through to the id check? Those are different problems.

1. `SecOC_Init()` returning is not proof of successful initialization

The local Vector API returns void. In SecOC.c, the success path sets the internal initialized state only at line 205:

SecOC_SetDevModeEnabled(FALSE);
SecOC_SetInitialized(TRUE);

Earlier, SecOC_Init() can set a nonzero local errorId for a repeated init, a null configured init pointer, or a final magic-number mismatch. It still reaches the function end; the caller receives no E_OK.

Therefore: “I saw SecOC_Init() and it returned” does not prove the RX state is initialized. Break on the success assignment and inspect the error path/DET report.

2. Debug the init state transition

Set breakpoints in this order:

  1. SecOC_InitMemory() — it sets initialized FALSE.
  2. SecOC_Init() entry and its error branches.
  3. The success block at SecOC.c:198–205, especially SecOC_SetInitialized(TRUE).
  4. SecOC_DeInit() — it also sets initialized FALSE.
  5. SecOC_RxIndication() at SecOC_RxIf.c:224.

Inspect whether SecOC_InitMemory() or SecOC_DeInit() runs after the successful set. If the flag becomes TRUE and later is FALSE, find the intervening write/reset. If the debugger cannot watch the accessor, inspect its definition in the generated SecOC headers/configuration and set a watchpoint on its actual backing state.

3. Use DET to distinguish init errors

SecOC_Init() keeps its error in a local variable and reports it through SecOC_ReportDetError(SECOC_SID_INIT, errorId). DET reporting only happens when SECOC_DEV_ERROR_REPORT is enabled; that is separate from SECOC_DEV_ERROR_DETECT, which enables runtime parameter checks.

Observed DET/API resultMeaning to investigate
API 0x01, error 7Initialization failed: check configured init pointer and final magic-number/configuration.
API 0x01, error 2Init was called while the module already reported initialized; inspect duplicate/partition startup calls and call order.
API 0x42, error 2SecOC_RxIndication saw the module as uninitialized at runtime.

4. If initialization passes, then inspect the PDU ID

Only after the init condition is false does the function evaluate:

id >= SecOC_GetSizeOfRxSecuredPduInfo()

If true, SECOC_E_INVALID_PDU_SDU_ID is assigned. If it is false, the next generated-handle check can assign the same error at SecOC_RxIf.c:238–240.

At the breakpoint, record:

id
SecOC_GetSizeOfRxSecuredPduInfo()
SecOC_IsInvalidHndOfRxSecuredPduInfo(id)

id is used as the generated SecOC secured-RX-PDU handle/index here. Do not assume it is the CAN identifier, a COM signal ID, or the Authentic-PDU destination handle. Check the generated CanIf/PduR route and SecOC RX handle table together.

5. Only then move to pointer and length checks

After the ID and handle pass, the code checks null pointers, configured metadata, minimum length, and configured secured-PDU length. For HV_BATT the CANoe bus frame is 8 bytes, but compare against the values in the generated SecOC configuration at runtime.

error 1 → NULL pointer / required metadata pointer
error 5 → invalid or too-short PDU length
error 10 → runtime buffer busy (reported separately)

Focused next run

  1. At RX entry, capture whether the init branch is taken.
  2. If taken, inspect whether SecOC_SetInitialized(TRUE) was ever executed and whether a later reset/deinit occurs.
  3. If not taken, step to the ID comparison and record id and generated RX table size.
  4. Continue into the invalid-handle check; do not stop at the bounds check alone.
  5. Read the final errorId or the DET record, since SecOC_RxIndication() itself returns void.
Do not force the initialized flag TRUE, remove the development check, or change the PDU ID before learning which branch is actually taken.

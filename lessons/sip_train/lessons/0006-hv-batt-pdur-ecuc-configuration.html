Lesson 06 · one verified configuration win

Configure the two-hop SecOC receive path

Today’s win: distinguish the 8-byte secured PDU from the 5-byte Authentic PDU, then configure PduR so authentication cannot be bypassed.

Predict first: Should COM receive 8 bytes or 5 bytes? Answer: 5 bytes, only after verification.

Step 1 — freeze the contract

Secured CAN PDU:  8 bytes
Authentic PDU:    5 bytes = payload + two authenticated 0x00 bytes
Authenticator:    3 bytes = 24-bit truncated CMAC
Freshness:        0 bytes

With 1-based byte numbering, MAC bytes 6–8. If a document says MAC bytes 5–7, it is using zero-based numbering or leaves byte 8 undefined; resolve that before configuring.

Step 2 — configure SecOC

  1. Create the RX processing container.
  2. Create SecOCRxSecuredPduLayer → SecOCRxSecuredPdu; reference the global secured PDU of length 8.
  3. Set SecOCSecuredRxPduVerification = TRUE.
  4. Create the Authentic PDU layer; reference a distinct global Authentic PDU of length 5.
  5. Set authenticator truncation to 24 bits and both freshness lengths to 0. Disable AuthData freshness.
  6. Reference the CSM MAC-verify job.

Step 3 — configure PduR Path A

CanIf Rx secured PDU (8)
  → PduR source: secured global PDU
  → PduR destination: SecOC secured endpoint
  → SecOC_RxIndication

Use an IF routing path, direct provision, and no TP queue for the single Classical CAN frame. Never set the destination to COM.

Step 4 — configure PduR Path B

SecOC verified Authentic PDU (5)
  → PduR source: SecOC authentic-layer PDU
  → PduR destination: COM authentic PDU
  → Com_RxIndication

COM must model the 5-byte authentic data, not the MAC-bearing 8-byte frame.

Step 5 — verify generated behavior

  • CanIf receive path reaches SecOC, not COM.
  • CSM verifies DataId || AuthenticPdu against the received MAC.
  • Only successful verification reaches COM, with SduLength = 5.
  • Do not hand-edit calculated PduR handles, direction, routing type, or communication type.

Primary source

AUTOSAR CP R23-11 SecOC SWS and the configuration reference card.

CANoe setup order

  1. Add DBC and verify DLC 8.
  2. Display bytes 0–7 in Trace.
  3. Open Security Configuration/Security Manager.
  4. Add SecOC protected-PDU object.
  5. Map it to the secured database message/controller port.
  6. Configure Data ID, profile, offsets, lengths, and test key.
  7. Generate valid traffic and compare bytes.

Negative tests

change byte 0..2, keep MAC → reject
change byte 3..4, keep MAC → reject
change byte 5..7             → reject
replay valid frame           → may accept: no FV
CANoe 12 caveat: exact labels, profile-file format, DBC-versus-ARXML import behavior, CAPL APIs, and OEM add-on requirements are version/license dependent. Verify against the installed CANoe 12 Help.

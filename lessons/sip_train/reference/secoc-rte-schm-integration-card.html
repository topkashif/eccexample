HV_BATT first-test recommendation

  • RX only; do not compile TX-only functionality out by deleting source.
  • Use a complete generated SecOC configuration.
  • Set verification-status propagation to NONE if the application does not need it.
  • Use SecOCQueryFreshness = CFUNC only when that is the project’s real configured mode; no fabricated freshness RTE port.
  • Keep SecOCSecuredRxPduVerification = TRUE.
  • Verify: CanIf/PduR → SecOC_RxIndication → Csm_MacVerify → verified Authentic PDU → PduR/COM.
Release matching: the local SecOC source reports MICROSAR 19.02.06. Generated SecOC, SchM, RTE, PduR, CSM, and Cry artifacts must match the installed package and configuration variant.

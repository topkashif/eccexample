When Path A currently references COM

  1. Determine whether the route is genuinely CanIf → COM or only a global-PDU ownership display.
  2. Inspect generated code: Path A must eventually call SecOC_RxIndication.
  3. If it calls Com_RxIndication, remove/disable the direct route.
  4. Set Path A destination to the SecOC secured-PDU endpoint.
  5. Create Path B from the SecOC authentic-layer PDU to the COM Authentic PDU.
  6. Regenerate; do not edit calculated handle IDs, direction, or routing type.

SecOC RX blocked at init or PDU-ID check?

Branch order in SecOC_RxIndication

1. !SecOC_IsInitialized()         → E_UNINIT (2)
2. id >= generated RX table size  → E_INVALID_PDU_SDU_ID (3)
3. invalid generated RX handle    → E_INVALID_PDU_SDU_ID (3)
4. NULL pointer / metadata checks
5. min/configured secured length

If check 1 is true, the current frame’s ID, pointer, length, MAC, and key have not been evaluated yet.

Init does not return success/failure

SecOC_Init() returns void
success path calls SecOC_SetInitialized(TRUE)
SecOC_InitMemory() sets it FALSE
SecOC_DeInit() sets it FALSE

Break at the successful setter and at later reset/deinit calls. A visible return from SecOC_Init() alone proves nothing about success.

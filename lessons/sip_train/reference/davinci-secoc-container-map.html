Length sanity check

Physical CAN secured PDU:  8 bytes = Authentic[5] || MAC[3]
SecOC Authentic PDU:       5 bytes = CAN[0]..CAN[4]
DataToAuthenticator:       7 bytes = DataId[2] || Authentic[5]
Received authenticator:     3 bytes = CAN[5]..CAN[7]

Generated-code checkpoints

  • CanIf accepts only the intended Classical CAN frame and length 8.
  • PduR has both routes and does not change the payload.
  • SecOC references the same secured PDU and authentic PDU as PduR.
  • Generated SecOC calls Csm_MacVerify with 7-byte data and 24-bit received MAC.
  • CSM job resolves to AES-CMAC verify and the intended key/queue.
  • Successful verification alone causes the 5-byte Authentic PDU to be forwarded.
